# Генератор списка покупок

Веб-приложение для автоматического составления списка продуктов на основе названия блюда и количества персон. Использует нейросети OpenRouter с автоматическим выбором доступной модели и fallback при сбоях.

## Архитектура

Проект состоит из двух частей:

- **Бэкенд** (`backend/`) — FastAPI-приложение, которое общается с OpenRouter API, обрабатывает запросы и валидирует данные
- **Фронтенд** (`frontend/streamlit_app.py`) — Streamlit-интерфейс, через который пользователь вводит блюдо и получает результат

### Схема работы

```
Пользователь → Streamlit UI → FastAPI (/generate) → OpenRouter (автовыбор модели) → Результат → Пользователь
```

## Первоначальная настройка

### 1. Клонирование репозитория

Склонируйте проект на локальную машину:

```powershell
git clone <url-вашего-репозитория>
cd fastApiProject
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```powershell
pip install -r requirements.txt
```

### 4. Настройка API ключа OpenRouter

1. Зарегистрируйтесь на [OpenRouter](https://openrouter.ai/)
2. Перейдите в [раздел Keys](https://openrouter.ai/keys) и создайте новый ключ
3. В корне проекта создайте файл `.env` на основе шаблона:

```powershell
copy .env.example .env
```

4. Откройте файл `.env` и вставьте ваш ключ в поле `OPENROUTER_API_KEY`:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-фактический-ключ
```

> Файл `.env` содержит чувствительные данные и не должен попадать в репозиторий.

## Запуск

### Запуск бэкенда

```powershell
cd G:\fastApiProject
uvicorn backend.main:app --reload --port 8000
```

Бэкенд доступен по адресу `http://localhost:8000`.

При старте OpenRouter-клиент автоматически загружает список бесплатных моделей (без модерационных, vision и safety-моделей). В логах отобразится количество загруженных моделей:

```
✅ API ключ OpenRouter настроен, загрузка списка моделей...
✅ Загружено N бесплатных моделей
```

### Запуск фронтенда

В отдельном окне терминала:

```powershell
cd G:\fastApiProject
streamlit run frontend/streamlit_app.py
```

Фронтенд откроется в браузере по адресу `http://localhost:8501`.

## API endpoints

### GET /health

Проверка здоровья сервиса и статуса конфигурации API.

**Ответ:**

```json
{
  "status": "healthy",
  "api_configured": true
}
```

- `status` — состояние сервиса (`healthy`)
- `api_configured` — `true`, если ключ OpenRouter загружен и не пустой

### POST /generate

Генерация списка покупок.

**Тело запроса:**

```json
{
  "dish": "Борщ",
  "people": "4",
  "output_format": "Список + шаги"
}
```

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `dish` | string | Название блюда (1–500 символов) |
| `people` | string | Количество персон: `1`, `2`, `4`, `6` |
| `output_format` | string | `Список продуктов` или `Список + шаги` |

**Успешный ответ (200):**

```json
{
  "success": true,
  "result": "Молоко — 800 мл\nЯйца — 8 шт\n...",
  "model_used": "Llama 3.3 70B (free)"
}
```

**Ошибки:**

| Код | Причина |
|-----|---------|
| 422 | Некорректный формат запроса (проверьте введённые данные) |
| 503 | Все модели временно недоступны |
| 500 | Внутренняя ошибка или все попытки генерации исчерпаны |

### GET /

Корневой эндпоинт, возвращает информацию о сервисе.

## Автовыбор модели

Бэкенд при старте делает запрос к `https://openrouter.ai/api/v1/models` и фильтрует список:

1. Оставляются только модели с пометкой `:free`
2. Исключаются vision/multimodal (`-vl`, `vision`, `multimodal`, `omni`)
3. Исключаются модерационные (`safety`, `content-safety`)

При генерации запроса:
- Модели перебираются из загруженного списка по порядку
- При ошибке (429, 5xx, timeout) — модель временно помечается как недоступная на 60 секунд, выбирается следующая
- Если все модели исчерпаны — возвращается ошибка 503

## Конфигурация

### Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|------------|:-----------:|-------------|---------|
| `OPENROUTER_API_KEY` | Да | — | Ключ OpenRouter |
| `OPENROUTER_SITE_URL` | Нет | `http://localhost:8000` | URL для заголовка HTTP-Referer |
| `OPENROUTER_APP_NAME` | Нет | `ShoppingListAPI` | Имя приложения в заголовке X-Title |
| `API_URL` | Нет | `http://localhost:8000` | Базовый URL API для фронтенда |
| `MOCK_MODE` | Нет | `false` | `true` — возвращать заглушки вместо запросов к нейросети |

### MOCK-режим

При `MOCK_MODE=true` бэкенд не обращается к OpenRouter, а возвращает фиксированный шаблонный ответ. Используется для отладки фронтенда без ключа API.

## Техподдержка: типичные проблемы

### "API сервер недоступен" / "Не удалось подключиться к API"

**Причины:**
- Бэкенд не запущен или запущен на другом порту
- Бэкенд запущен из другой директории, где нет `.env`

**Решение:**
1. Проверьте, что процесс uvicorn запущен: `tasklist /FI "IMAGENAME eq python.exe" /V`
2. Проверьте адрес: откройте в браузере `http://localhost:8000/health`
3. Если `/health` не открывается, запустите бэкенд заново из `G:\fastApiProject`
4. Если `/health` доступен, но возвращает `api_configured: false` — проверьте файл `.env`

### "API ключ не настроен" (frontend) хотя ключ в `.env` есть

**Причины:**
- Бэкенд запущен до создания/изменения `.env` — процесс не подхватил изменения
- Бэкенд запущен не из корня проекта
- В `.env` есть лишние пробелы или нестандартные кавычки

**Решение:**
```powershell
# 1. Остановите бэкенд (Ctrl+C)
# 2. Проверьте содержимое .env
type G:\fastApiProject\.env

# 3. Запустите заново ИЗ корня проекта
cd G:\fastApiProject
uvicorn backend.main:app --reload --port 8000
```

### "Cannot read image.png (this model does not support image input)"

**Причина:** выбранная модель является multimodal/vision, а в запросе передаётся только текст.

**Решение:**
Бэкенд фильтрует такие модели автоматически. Если ошибка повторяется:

1. Остановите бэкенд
2. Перезапустите — при старте заново подтянется актуальный список моделей
3. Если не помогает — проверьте логи на старте: должно быть `✅ Загружено N бесплатных моделей`

### "Не удалось получить ответ от доступных моделей"

**Причины:**
- Все бесплатные модели OpenRouter перегружены (rate limit)
- Сеть нестабильна, все запросы падают по таймауту

**Решение:**
- Подождите 1–2 минуты и попробуйте снова
- Проверьте интернет-соединение
- Убедитесь, что ключ OpenRouter валиден: откройте `https://openrouter.ai/keys` и проверьте баланс/статус

### "Пустой ответ модели. Попробуйте переформулировать вопрос"

**Причина:** OpenRouter вернул пустой или некорректный ответ. Модель пометина как временно недоступная, бэкенд попробовал следующую, но все попытки исчерпаны.

**Решение:** переформулируйте запрос или подождите несколько минут.

### Проблемы с кэшем Streamlit

Если интерфейс ведёт себя нестабильно, обновляет старые данные или выводит мусор:

```powershell
streamlit cache clear
```

## Используемые технологии

- **FastAPI** — бэкенд API
- **Streamlit** — веб-интерфейс
- **OpenRouter** — платформа для работы с LLM

- **pydantic** — валидация данных
- **python-dotenv** — управление переменными окружения

## Примечания

- Бесплатные модели OpenRouter имеют ограничения по скорости (rate limit). Если модель перегружена, бэкенд автоматически переключится на другую.
- Не добавляйте статические списки моделей в код — OpenRouter обновляет свой каталог постоянно. Бэкенд загружает актуальный список при каждом запуске.
- Файл `.env` не должен попадать в репозиторий.
